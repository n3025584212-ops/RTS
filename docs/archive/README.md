# FRONTLINE archive

Everything under this directory is retained for provenance, recovery and reusable evidence.

ARCHIVE_STATUS=HISTORICAL_REFERENCE
CURRENT_AUTHORITY=NO

Archived material can be consulted when useful, but must not override:

1. explicit user/product-owner decisions;
2. `docs/current/CURRENT_STATE.md`;
3. accepted current decisions;
4. the active task Issue.

Folders:

- `battle01/` — historical Battle01 product, AI, formation, runtime and vertical-slice contracts.
- `governance/` — superseded project baselines/charters/execution governance.
- `visual_targets/` — historical visual targets retained as references, not active production requirements.

Do not delete archived files merely because they are inactive; remove only when they are proven redundant and have no recovery/evidence value.
